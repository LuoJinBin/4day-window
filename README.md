# 随心出行 · 天气规划

一个可以自己选择**目的地、日期范围、连续出行天数和具体时段**的天气规划页面。

线上地址：https://guangzhou-4day-window.vercel.app/

## 能做什么

- **全球城市搜索**：输入城市名，选择国家/地区相同的地点；展示当地时区。
- **查指定日期**：查看单日或连续多天的天气。
- **帮你找日期**：选择搜索范围和连续 1–7 天，比较可用日期并给出备选。
- **选择时段**：全天（06:00–22:00）、上午、下午、晚上，或自定义开始/结束时间。
- **逐小时详情**：查看天气、温度、降雨概率、雨量和风速；展开每天即可查看小时明细。
- **出行偏好**：可以选择尽量避雨，或接受短时小雨。

日期、星期和时段都按目的地当地时区计算。预报接口最多提供未来 16 天；越远的日期参考价值越低，页面会降低预报参考度。

## 天气数据与使用边界

- 城市搜索使用 Open-Meteo Geocoding API，地点数据基于 GeoNames。
- 天气使用 Open-Meteo Forecast API；优先综合六个数值模式，若上游不接受模式组合，则回退到最佳匹配模式。
- 每个城市使用搜索结果对应的代表坐标，不代表整个城市每个街区；沿海、山区和郊区可能存在局地差异。
- 逐小时降雨概率、雨量和天气现象是预报信号，不是确定结果。结果用于行程参考，出发前应再次查看临近预报。
- 天气查询按坐标缓存 20 分钟；上游暂时失败时，最多使用 6 小时内的旧结果，并明确标记旧数据。
- 免费公共接口可能限流；不通过代理轮换或其他方式规避限制。

## 运行

要求 Node.js **>= 22**。仓库没有额外运行时依赖。

    npm install
    cp .env.example .env
    npm start

默认只监听 127.0.0.1:8787。容器或 Render 等托管环境需要显式设置 HOST=0.0.0.0。

## 接口

| 路径 | 用途 |
| --- | --- |
| GET /api/locations?q=东京 | 城市搜索，返回坐标、行政区和时区 |
| GET /api/plan?lat=35.6762&lon=139.6503 | 取得 16 天逐日与逐小时预报 |
| GET /api/health | 本地旧预报服务状态 |
| GET /api/forecast | 旧版广州四天监测接口，暂时保留兼容 |

Vercel 部署使用 api/locations.js 与 api/plan.js 两个函数；本地 Node 服务也提供相同路由。

## 旧版广州研究资料

仓库中的 app-core.js、app-runtime.js、app-charts.js 和 data/ 保留了早期广州四天窗口模型、历史统计与回测资料。新页面不再加载旧版固定广州界面；旧接口和研究资料暂时保留，避免丢失原有成果。
